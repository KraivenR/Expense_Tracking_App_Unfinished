# Expense Tracking App

An Android expense tracking application currently under development. The goal of this project is to provide a simple and intuitive way for users to manage their personal expenses, monitor spending, and keep track of upcoming payments.

> 🚧 **Project Status: Unfinished / In Development**

## Overview

The Expense Tracking App is a personal finance management application built for Android. The project focuses on creating a clean user interface while implementing features for recording expenses, organizing transactions, managing recurring payments, and viewing spending information.

This project is still under development, and some features may be incomplete or subject to change.

## Planned Features

- 💰 Add and manage expenses
- 📝 Edit and delete transactions
- 🗂️ Organize expenses by categories
- 📊 View spending summaries
- 📅 Calendar-based expense tracking
- 🔄 Manage recurring bills and payments
- 💳 Track upcoming payments
- 📈 Display spending statistics
- 💾 Store and manage expense data
- 🔔 Notifications for upcoming payments

## Current Features

The current version includes parts of the application's user interface and navigation system, including:

- Main expense tracking dashboard
- Upcoming payments section
- Recent transactions section
- Calendar interface
- Bottom navigation
- Expense-related UI components
- RecyclerViews for displaying lists of information

More functionality is currently being implemented.
